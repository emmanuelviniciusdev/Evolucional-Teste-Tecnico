# Evolucional technical test

School enrollment API on .NET Framework 4.8.

The runnable backend lives in [`apps/backend`](apps/backend). Follow [`apps/backend/README.md`](apps/backend/README.md) to restore packages, start SQL Server and Redis with Docker, run the Web API on Windows, and call `GET /api/health`.

Assignment business endpoints (alunos, turmas, matrículas, and relatórios) are not implemented yet.
